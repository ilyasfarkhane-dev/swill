# Swillbox Maroc

Site vitrine React + Vite pour un service de location de photobooths livrés sur le lieu de l’événement, au Maroc.

## Lancer en local

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run test:sites
```

Les pages sont dans `src/pages`. Les textes et coordonnées éditables sont dans `src/data`. Les visuels sont dans `public/assets`.
